## 1Gbps 端口和「1Gbps 随便跑」是两回事

「1Gbps」描述的是端口速率，也就是这一秒最多能跑多快；「2T 月流量」才是你这个月总共能搬多少数据。这两个数字互相牵制，很多人只看了前者。

把月流量摊到 30 天，平均持续速率是这样的（按 30 天折算的换算值，不是官方口径）：

- 2T / 月 ≈ 平均 **6Mbps** 出头
- 3.5T / 月 ≈ 11Mbps
- 7T / 月 ≈ 22Mbps
- 12T / 月 ≈ 37Mbps
- 20T / 月 ≈ 62Mbps

反过来说，如果真拿 1Gbps 端口连续跑满一个月，一个月要搬大约 **324TB** 数据。全系最高的 20T 套餐，也只够跑满 1Gbps 大约一天半。

所以 1Gbps 在这里的含义是「突发能冲上去」，不是「整月都能保持」。下载几十 GB 的系统镜像、临时拉一批数据、白天做一次压力测试，端口速率是有用的；指望它 7×24 挂 BT 或者做大流量中转，先撞上的是月流量额度，不是端口上限。

真正按「持续跑满」卖的产品在另一条线上，后面单独讲。

## 流量用超了会怎样，以及几个和带宽相关的坑

这个问题官方在 LowEndTalk 的活动帖里正面回答过：快到额度时会发邮件提醒，这时可以选择升级套餐，也可以等月初流量重置；如果不升级，流量用尽后 VPS 会被自动暂停，暂停状态一直持续到升级或者次月 1 日流量重置后自动恢复。流量每月 1 日重置。

也就是说，超流量的后果是停机，不是限速，也没有按 GB 计费的超额账单。做长期挂机任务的，把监控做起来，别等邮件来了才发现。

其余几条容易踩的：

**IP 被墙**。购买后 72 小时内可以在面板点 Change IP 自助免费更换，超过 72 小时换一次收 $3。收到机器第一件事就是测 IP 通不通。

**IPv6 要发工单**。洛杉矶 DC02、DC03 和圣何塞这三个机房可以免费额外分配 IPv6，不会自动给，得开工单申请。

**活动款不叠加优惠码**。活动套餐本身已是特价，通常不能再叠折扣。常规 KVM 套餐（非活动价）可以试 `INTENSEINVESTOR` 和 `DRWOOKIEE`，都是循环 30% 折扣，月付年付都适用；`WIN-30OFF` 是 Windows VPS 专用，`15OFFDEDI` 是独立服务器专用。下单时确认折扣真的应用上了再付款，不同批次的规则可能微调。

**流量翻倍要在论坛申请**。活动套餐可以在 LowEndTalk 指定帖里评论订单号申请流量翻倍，等于白拿一倍额度。这条以活动帖当前的说明为准，不是所有批次都有。

**线路性质**。普通 BGP 直连，没有 CN2 GIA 这类优化线路，晚高峰波动属于常态。拿它当反代源站、套 Cloudflare、做备用节点很合适，要求 4K 秒开或者对延迟极度敏感的业务，这个价位给不了。
